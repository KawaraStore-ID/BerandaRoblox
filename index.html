— FAQ

Pertanyaan Umum

Berapa lama waktu pengerjaan map? +
Tergantung kompleksitas map. Map sederhana 3–5 hari kerja, map menengah 7–14 hari, map kompleks bisa lebih. Estimasi diberikan saat konsultasi.
Apakah topup Robux aman tanpa login? +
Aman! Topup dilakukan via gamepass — kamu tidak perlu memberikan password atau akses akun Roblox sama sekali. Cukup kirim username dan nominal yang diinginkan.
Apakah map bisa request apa saja? +
Hampir semua tipe map bisa! Obby, roleplay, simulator, tycoon, PvP, dan lainnya. Konsultasikan dulu dengan admin untuk kepastiannya.
Apakah map termasuk script / coding? +
Paket standar mencakup build map (modeling & desain). Script sederhana bisa ditambahkan untuk paket kompleks dengan biaya tambahan.
Bagaimana sistem pembayaran map? +
DP 50% di awal, pelunasan 50% setelah map selesai dan kamu setuju. Pembayaran via transfer bank / e-wallet (dikonfirmasi saat order).
Berapa kali bisa revisi map? +
Tergantung paket: Sederhana 1x, Menengah 2x, Kompleks fleksibel. Revisi di luar ketentuan bisa dibicarakan dengan biaya tambahan.
