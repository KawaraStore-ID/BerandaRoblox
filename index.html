— FAQ

Pertanyaan Umum

Berapa lama waktu pengerjaan? +
Tergantung kompleksitas map. Map sederhana bisa 3–5 hari kerja, map menengah 7–14 hari, map kompleks bisa lebih. Estimasi diberikan saat konsultasi.
Apakah bisa request apa saja? +
Hampir semua tipe map bisa! Obby, roleplay, simulator, tycoon, PvP, dan lainnya. Konsultasikan dulu dengan admin untuk kepastiannya.
Apakah termasuk script / coding? +
Paket standar mencakup build map (modeling & desain). Script sederhana bisa ditambahkan untuk paket kompleks dengan biaya tambahan, tergantung kebutuhan.
Bagaimana sistem pembayaran? +
DP 50% di awal, pelunasan 50% setelah map selesai dan kamu setuju. Pembayaran via transfer bank / e-wallet (dikonfirmasi saat order).
Berapa kali bisa revisi? +
Tergantung paket: Sederhana 1x, Menengah 2x, Kompleks fleksibel. Revisi di luar ketentuan bisa dibicarakan dengan biaya tambahan.
